# Playbook acceptance

W01–W13 have one versioned `commands.json` each. See
[the runner guide](../docs/playbooks.md) for installation, generated inputs,
feature skips, hash projections and the container check.

The inputs are generated by `scripts/gen-playbook-fixtures.py` and recorded in
`inputs/provenance.json` with SHA-256 and MIT OR Apache-2.0 provenance. They
contain no downloaded images, fonts, models or measured application timings.
