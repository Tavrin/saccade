# Retain and replay a visual finding

These fixtures are procedural screenshots generated by `gen-guide-fixtures.py`
(CC0-1.0). See [the replay contract](../replay.md) for OCR, limits and identities.

```sh case=known-good exit=0 says="reproduced"
cat > recipe.json <<'JSON'
{"schema":"saccade-replay-recipe.v1","run":{"operation":"compare","a":"samples/ui/baseline","b":"samples/ui/same","threshold":0.01,"metric":"mean","ppd":67.0}}
JSON
saccade replay pack recipe.json --out pack --json
saccade replay verify pack --json
```

Changing a retained input refuses verification before any measurement:

```sh case=known-bad exit=2 says="replay_input_changed"
printf changed > pack/inputs/a/login.png
saccade replay verify pack --json
```

```sh case=missing-input exit=2
saccade replay pack absent-recipe.json --out absent-pack --json
```

An explicit OCR registry id cannot use an ambient model or fall back:

```sh case=unavailable-dependency exit=2
cat > unavailable.json <<'JSON'
{"schema":"saccade-replay-recipe.v1","run":{"operation":"text","a":"samples/ui/baseline/login.png","b":"samples/ui/same/login.png","a_source":null,"b_source":null,"ocr":{"registry":"missing-registry.json","contract_id":"ocr","library":"missing-runtime.so"},"expect_text":[],"readable_confidence":80.0,"moved_px":3.0}}
JSON
saccade replay pack unavailable.json --out unavailable-pack --json
```
