| ID | Finding | Disposition | Fix |
|---|---|---|---|
| M1 | A non-finite or ≤0 `ppd` gives NaN metrics, and the report can't be read back. | Accept | Reject `ppd` unless it is finite and >0 (exit 2). Serialize non-finite metric values as `null` and make the model fields tolerate that, or clamp them; either way the report must round-trip. |
| M2 | Alpha is dropped silently. | Accept | When either image has alpha <255, composite both over black and over white, run FLIP on each, and take the per-pixel max. This catches alpha-only changes and ignores RGB hidden under alpha 0. Document it in the README and the rustdoc. |
| M3 | A stale report survives a failed run. | Accept | At the start of `run`, remove `flipdiff-report.v1.json`, `index.html` and `images/` from the report dir, and only those. Never touch other files. |
| M4 | Matrix jobs collide on the artifact name and comment. | Accept | Add an `artifact-name` input (default `flipdiff-report`) and a `comment-key` input (default empty). The marker becomes `<!-- flipdiff-summary:<key> -->`. The README documents matrix use. |
| M5 | Symlinks are followed. | Accept | Don't follow links. A symlink entry becomes an `error` entry ("symlinks are not followed"). |
| M6 | A per-image IO error aborts the run. | Accept | Walk errors and copy errors become `error` entries, as SPEC §2 requires. |
| m1 | Broken pipe panics. | Accept | Write stdout with `writeln!`; treat `BrokenPipe` as exit 0 or the current code, never a panic. |
| m2 | Newlines in names inject workflow commands. | Accept | Escape control characters in names in the text table (as `\n`, `\x1b`, and so on). |
| m3 | Markdown error rows are unsanitized. | Accept | Put the error text in a code span, with the same escaping as names. |
| m4 | `approve` writes through symlinks. | Accept | Refuse when any existing component of the destination path under `baseline_dir` is a symlink. |
| m5 | An undecodable capture with no baseline stays `new`. | Accept | Decode the capture; on failure it becomes `error`. |
| m6 | Size changes can't be approved in bulk. | Accept, cheap | Add `approve --include-errors`, which takes `error` entries whose capture exists and decodes. |
| m7 | Negative NaN sorts as smallest. | Accept | Map every NaN to +∞ before sorting. |
| m8 | Glob case doesn't match extension case. | Accept | Make globs case-insensitive (globset `case_insensitive(true)`). |
| m9 | Release install is unverified. | Partly | The release workflow publishes a `.sha256` for each asset; the action verifies it and runs `flipdiff --version`, falling back to a source build on mismatch. Private-repo access is out of scope (human publishing decision). |
| m10 | An absolute `report-dir` means no upload. | Accept | Document it in the `action.yml` input description and the README. |
| m11 | Can't turn off `fail_on_new` from the CLI. | Record only | |
| m12 | README says "only 8-bit". | Accept | Correct it: 16-bit PNGs are accepted and down-converted. |
| m13 | A tiny `max_bytes` drops the marker. | Refuted | The CLI can't reach it. Recorded only. |
