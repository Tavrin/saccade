# Brand, theme and accessibility review

Run `saccade review brand source.json --config saccade.toml --out brand.json`.
The packet keeps named colour drift, source-backed contrast, chart confusability
and typography findings together. It does not calculate a combined score or
approve a release. Exit 1 means a failure, a review finding or missing required
swatch evidence. APCA's unavailable status is informational.

Declare targets and thresholds in the project file:

```toml
[[brand.swatches]]
name = "logo_red"
colour = { rgb = [1.0, 0.0, 0.0], profile = "srgb" }
delta_e2000 = 2.0

[[brand.cvd]]
names = ["series_a", "series_b"]
kind = "deutan"
severity = 0.5
minimum_delta_e2000 = 5.0

[brand.profiles.export]
path = "profiles/export.icc"
sha256 = "sha256:0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
```

External profiles are RGB matrix/shaper ICC profiles with exact SHA-256 pins;
paths are relative to the configuration. Builtin `srgb` and `display_p3` profiles
are generated by pinned moxcms 0.7.11 and their profile-byte hashes are recorded.
The supported intent is `relative_colorimetric`, with `bradford_icc_pcs`
adaptation: ICC D50 colorants transform to linear sRGB/D65. Unsupported intents,
LUT profiles and missing pins are errors. There is no display calibration or
CMYK proofing. Float transforms preserve out-of-gamut values for colour distance;
Machado simulation explicitly clips its output to the sRGB gamut.

Export `saccade-brand-source.v1` JSON from the source producer:

```json
{
  "schema": "saccade-brand-source.v1",
  "source_artifact": "capture-dom.json",
  "source_sha256": "sha256:0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef",
  "rendering_intent": "relative_colorimetric",
  "chromatic_adaptation": "bradford_icc_pcs",
  "samples": [{"name":"logo_red", "colour":{"rgb":[0.95,0.01,0.01],"profile":"srgb"}, "source":"#logo fill"}],
  "text": [{"id":"price", "source":"#price computed style", "foreground":[0.5,0.5,0.5,1.0], "backgrounds":[[1.0,1.0,1.0]], "font_size_px":16.0, "font_weight":400}]
}
```

Replace illustrative hashes with hashes of actual bytes. The CLI verifies the
source artifact. The producer supplies samples and text facts; Saccade does not
recapture the DOM or infer source semantics from screenshot colour clustering.
Store sampling coordinates/CSS locators in `source`. Include all effective opaque
background samples, including gradient extrema; foreground alpha composites in
encoded sRGB. WCAG 2.2 SC 1.4.3 uses 4.5 for ordinary text and 3 for at least 24
CSS px or bold text at least 18⅔ px. Results retain exact, unrounded ratios and
assume the declared text is non-exempt. This is a bounded rule check, not site
certification. Optional `font`, `expected_font`, `missing_glyphs`, `ink_box` and
`clip_box` permit typography and glyph-ink clipping findings. DOM element bounds
alone are insufficient to prove glyph clipping.

For HDR swatches use `bt2020_pq` encoded RGB in [0,1] with `delta_e_itp` instead
of `delta_e2000`. ST 2084 is absolute, normalized to 10000 cd/m². BT.2100 ICtCp
and BT.2124 ΔE-ITP apply the Ct/2 scaling once. SDR/HDR mixing is rejected.
Thresholds describe sample colours, not whole-image perceptual quality.

Machado uses the published severity matrices with interpolation between 0.1
steps. Severity 1 is the dichromacy endpoint; intermediate severities describe
anomalous trichromacy. A confusable pair requests review, without claiming an
individual's task experience. APCA is labelled `apca_wcag_3_draft` and unavailable:
the reviewed implementation licence restricts commercial/field-of-use purposes.
It is not an adopted WCAG 3 compliance rule.
