# R5 local commands and MCP

Binding brief: SPEC-r5.md and DESIGN-1.0.md §§2–7, 11, 12 and 14.

## Decisions

1. The brief's non-goal names R5 command renames, which contradicts the explicit R5 goal and twelve-command Done-when. The explicit goal wins.
2. R5 exposes five local MCP tools. The binding dependency rule postpones `saccade_review` until R9–R11; no legacy provider tool remains callable. `review REPORT` previews locally. `--run` fails before dispatch until that transport exists. The four review sub-operations are present; evaluation execution and question generation from raw reports are explicitly unavailable until their owning lanes. R5 prepares an already validated closed request from a canonical case, validates proposals against it, and creates/retrieves unresolved request items without generating a question catalog.
3. The live required verifier confirmed four Moss failures at `scripts/moss-ablate.sh:372`: it strictly requires the `saccade-result.v1` discriminator. SPEC-r5 explicitly preserves that parsed shape and requires verifier PASS while forbidding Moss edits. The closest feasible reading freezes only CLI `identity --json`'s discriminator. Its content is the bounded shared envelope; compare and every MCP result use v2. There is no compatibility flag, legacy command alias, or selectable old-format writer. This is a documented exception to the design's v2 discriminator, required by the narrower preserved-interface constraint. The coordinator can move this discriminator to v2 after migrating the Moss reader. The shared envelope retains Moss's named mode, verdict, totals, failing error and report-path fields as documented fields of the shared contract. One shared measurement implementation supplies both transports. Historical schemas/readers remain. Capture validity, measured outcome and review authority remain separate.
4. `ablate` moves to `experiment ablate` with no alias. The checked Moss scripts contain no direct `saccade ablate` invocation; the operator example at `/mnt/linux-extra/moss-lane-worktrees/main-fix/docs/agents/specs/SPEC-PROBE-CACHE-KEY-DETERMINISM-2026-10-01.md:250` must use `saccade experiment ablate`; this worktree does not edit Moss. Compare, identity, noise and serve retain their command names, identity console wording, report markers and serving contracts.
5. Serve and MCP share the normalized RootPolicy registry. Startup roots are read-only; targets authorize storage only through root aliases. MCP outputs require a separate explicit out-root. Serve retains its existing default local cache/decision locations and bounded storage probes; explicit out-root feeds those generated locations. Project symlink-target settings cannot grant transport permission.
6. Image noise is explicit `image`/`FLIP`. Performance noise uses the existing dedicated TOML reader/writer representation, with `performance`/`ms` in its result. R6 owns qualified perf.v2 and wrong-noise-kind enforcement. No performance qualification claim is added here.
7. Bounded summaries preserve outcome, counts, validity and actions; full details remain in hashed artifacts. Cursor identity binds artifact bytes, selection and requested page size. Measurement continuations retain deterministic worst-first failing order and resume through inspect at page limit 10. Generated next-action arguments carry the actual local-tool discriminator and are exercised directly by contract tests. Stale action preconditions and changed referenced content fail closed. Grouped capture-invalidity reasons retain the total and the exact report reference.

## Strictly required changes outside the listed transport files

- Contract tests and showcase command generation/transcripts: required gates invoke the current interface rather than removed commands. Historical artifact validation remains covered.
