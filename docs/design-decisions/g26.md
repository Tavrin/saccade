# Captured transitions and animation

Separate `experiment transition` and `experiment animation` commands consume a
shared versioned capture plan. Static geometry identity and finite asset views
cannot establish animated or transition behaviour and are unchanged.

The plan declares each capture and timestamp explicitly. The existing sequence
contract in this revision has no frame-map, so this implementation uses plain
timestamp lists with strict reference/candidate equality. A future adapter may
populate the same observations from frame maps. The timestamps remain producer
assertions. Replacing the contract would require a new version; adding an
adapter would not.

Normalized RGB MAE reuses the settling implementation's tile trajectories.
Existing phase correlation and optional dense motion provide supplementary
alignment. Raw full-frame and local budgets preserve localized failures;
missing alignment support cannot establish animation consistency. Signed
residual changes catch flicker that scalar absolute-error curves would miss.
No dependencies, model provisioning, rendering or GPU capture were added.
Changing metric semantics would require a new packet version.

Single-sequence convergence uses the final image as an inferred target and a
pre-switch motion baseline. Independent reference captures enable a target that
moves over time and a same-timestamp paired steady-state difference. Without reference, the
steady difference compares pre/post windows and explicitly includes temporal
motion; its declared budget is still enforced. Steady-level
pairs cannot supply switch popping or duration, so those fields stay null.
The rejected alternative was inventing temporal evidence from static levels.
Obtaining missing evidence requires new captures, not an automatic fallback.

The procedural object-detail and progressive-raster fixtures exercise the same
command. Known switch, convergence and glitch indices are asserted, together
with missing captures, timestamp mismatch, frozen masks/IDs, path containment
and signed flicker. This qualifies constructed image observations only;
real asset acquisition/rendering, physical clocks, perceptual quality and
runtime performance remain unverified.

The required CLI suite exposed an existing review-denial test's dependence on
operator configuration. It now selects an absent policy inside its temporary
fixture explicitly. The expected denial assertion is preserved; production
review behaviour is unchanged. This keeps the gate local and deterministic.
