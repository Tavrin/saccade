Check $ARGUMENTS using the installed `saccade` binary. Choose `compare` for a
visual change, `prove identity` for an exact-image claim, or `prove performance`
for a speed claim with repeat directories. Put output outside captures and use
`--json`. Read bounded execution, validity, measurement, performance
comparability, local-change count, limits, and typed next actions. Follow an
action only with a current expected case identity and from its recorded `cwd`.
Inspect the named evidence and report what is established and unresolved.
Never approve or copy a baseline without explicit human authorization for the
exact selected content. No provider call is needed for the deterministic check.
