# Wave 5 decisions

- Scope and resources: implement only 5.1–5.6 on feat/wave5, no subagents. Heavy tests are written and queued through gates-wave5.sh, never run during development. Original images and baseline stores are preserved except explicit Playwright missing-snapshot update.
- Capture: share a Node stabilisation module between matcher and sweep. Clock/random setup before navigation is the reproducible driver path; matcher setup affects an already loaded page and cannot retroactively change application initialization. Rejected implicit navigation/reload because it changes test state. Reversal cost: add an opt-in navigation helper.
- Masks: use Saccade's declared fractional exclusions, retain reasons in matcher evidence. Selector masks on full-page images are refused (explicit rectangles work) because bounding boxes otherwise use viewport coordinates. Stability proposals never become exclusions. Rejected painting both screenshots because that loses excluded-area evidence. Reversal cost: extend full-page geometry collection.
- Profiles: named profiles and per-project defaults live in a bounded JSON package config; existing Saccade TOML remains accepted. Unknown profiles fail. Reversal cost: config translation only.
- Sweep: SHA-256 ranks URLs with a fixed seed and groups numeric/long-hex path segments. Rejected regex guessing of arbitrary slugs because it merges unrelated routes. Reversal cost: add explicit grouping rules in a later manifest version.
- Transport: new product commands use opt-in `products` (no default dependency change), bounded HTTP with no redirects, finite 429/503 backoff. Rejected forwarding credentials through redirects. Reversal cost: add explicitly allowlisted redirect policy.
- Last-good: existing history stores measurements, not human acceptance. Last-good means a complete deterministic passing report, never human approval. Preserve source-origin sidecars on new history records to resolve relative paths and verify every capture hash; legacy relative history without origin fails explicitly. Rejected guessing path bases or selecting an older run after a corrupt latest passing run. Reversal cost: migration tooling can provide explicit origins.
- Image tuning: exhaustive bounded grid, minimum bytes only among measured candidates; incomplete grids suppress selection. Rejected binary quality search because perceptual scores and HTTP negotiation need not be monotonic. Reversal cost: add an explicitly approximate search policy.
- Encoders: existing image JPEG and permissive image-webp lossless implementation; local WebP quality is ignored and evaluated once. Optional imgtune-avif enables image's ravif/rav1e encoder and dav1d decoder; coordinator provides the system library. Rejected default native decoder dependency. Reversal cost: switch the decoder behind the same adapter interface. AVIF compile/runtime remains a heavy prerequisite gate.
- Design-source: Figma REST execution is isolated by DesignSource; fixture mode requires no key/network and separate cache provenance. File version/scale/node selection bind cache hits. Unavailable variables (403) explicitly degrade to styles. Variable aliases and nonopaque/unsupported CSS colours remain unmeasurable. Rejected inferred colour/typography values. Reversal cost: extend normalized token adapter.
- Design alignment: use existing phase-correlation/compensated-error diagnostics while raw normal FLIP metrics decide. Responsive layout differences remain visible and unequal dimensions fail. Rejected automatic resizing/cropping that could hide layout errors. Reversal cost: add a separately declared supplementary alignment/resample policy after Wave 6 integration.
- Notification: explicit CLI notify only; generic summary/Slack plain-text/Teams Adaptive Card templates, HTTPS user env-file endpoint and optional bearer token. Rejected automatic posts during every compare because execution does not authorize messaging. Reversal cost: add an explicit opt-in orchestration flag.
- Genericity guard: external case-insensitive literal denylist, union of index/worktree tracked content and names, private terms never printed; absent list is an explicit skip. Rejected storing client terms/regex in fixtures or logs. Reversal cost: change external policy only.
- MCP: add saccade_products without changing existing six tools. Product HTTP and webhooks require independent human startup flags; neither tool arguments nor project JSON can authorize egress. Paths/config/retained history/capture references stay under the registry. MCP planning accepts URL lists; transitive sitemap expansion remains CLI-only (transport limitation, reversal cost: add a root-aware sitemap reader).
- Last-good snapshot source: prefer original encoded captures retained in the accepted report, because sweep's pair staging is temporary. Reject changed retained evidence; no fallback to an older run. HDR legacy paths still use their original encoded capture. Reversal cost: migrate HDR history into retained originals.
- Dependencies: optional AVIF uses ravif BSD-3-Clause/rav1e BSD-2-Clause, dav1d wrappers MIT, mp4parse MPL-2.0. Full resolved inventory is in THIRD_PARTY.md. Upstream rav1e resolves libfuzzer-sys only under cfg(fuzzing), whose NCSA component falls outside the requested licence list; that configuration is unsupported/unqualified and must not be distributed. Normal Wave 5 dependency trees exclude it. Reversal cost: upstream manifest/encoder change before qualifying fuzzing.
- Resource receipt: free space fell from 34 GB to 24/17 GB during concurrent lanes; Rust builds paused. Space recovered to 29 GB; permitted light checks resumed. Heavy gate script, browser tests, AVIF/system decoder checks, provider calls and CLI fixture script were not run during development.
