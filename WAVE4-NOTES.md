- Use a separate feature-gated assist module and immutable sidecars. Reject authority-bearing response fields through closed schemas. Rejected: changing grounded explanation or deterministic verdict contracts. Reversal cost: remove assist registrations and feature; existing reports remain readable.
- Reuse canonical digests, root policy, provider HTTP authorization and the existing locked ledger. Monetary accounting extends that ledger in an isolated additive namespace. Rejected: another independently trusted HTTP client or ambient credential lookup. Reversal cost: remove assist extension; persisted reservations remain conservative audit receipts.

Lane 2 decisions:

- Historical reports contain only aggregate masks. Require a report-hash-bound individual-membership manifest and verify its union; absent provenance is unavailable. Rejected: inventing component attribution from a union or recovering pre-masked pixels. Reversal cost: extend future capture producers to emit this manifest directly; historical missingness remains.
- Reconciliation requires exact canonical per-image statements/geometry/citations after blind remapping. Rejected: model-generated paraphrase agreement as independent truth. Reversal cost: preregister and qualify an additional reconciliation policy; current conservative policy can reduce coverage.
- Jev evidence-need routing is deferred until its incremental value is demonstrated. Deterministic rules, vision and dependent support are candidate experimental components, not retained qualified components. Reversal cost: enable a separately measured routing adapter and new policy epoch.
- Batch durable core operations exist, but a public CLI/MCP Batch network surface is deferred: it needs a frozen plan carrying verifiable transitive source references, not just embedded provider payloads. Interactive commands never wait on Batch. Reversal cost: add that plan contract and registrations; the existing lifecycle and request-hash adapter can be reused.

Lane 3 decisions and amendments:
- Freeze constructed-only seeds, family splits, renderer/font hashes, private oracle witnesses, task inputs, model bindings and the implementation fingerprint before provider results. Rejected: accepting mutation receipts or hand-entered answers as truth. Reversal cost: a new frozen epoch; existing results are not relabelled.
- Use procedural local PNGs and installed Pillow/DejaVu fixture tooling; no new Cargo dependencies, runtime models or redistributed font binaries. Local font licences/hashes are copied into each corpus and THIRD_PARTY records the fixture inputs. The coordinator permits crates.io fetching with fetched-source licence verification, but no new crate was needed. Reversal cost: replace the fixture renderer and freeze a new epoch.
- Independent root seeds vary geometry, colours, widths, font sizes and literal labels. Descendants, reverse orders and opposite-pixel routing probes retain one root/family/split. Rejected: treating repeated descendants as independent samples. Reversal cost: resample a new epoch and rerun all paired arms.
- Restrict committed model statements to an atomic visible-fact grammar. Literal text is untrusted transcription; causal/behavioral sentences are refused. The initial independent oracle scores presence/text and native appearance changes; unsupported clipping/overlap/line/colour assertions count against precision. Rejected: mechanically blessing arbitrary natural language. Reversal cost: extend and preregister the grammar/oracle in a new epoch; initial explanation coverage is conservative.
- Require exact Gemini countTokens before generation, through the existing HTTP/key/authorization/egress/attempt/money/pacing machinery. Each count consumes a conservative full reservation. Counting API billing is not specified, so aggregate Gemini cost stays unknown and the routing monetary value gate cannot qualify. Rejected: calling counting free or understating aggregate spend. Reversal cost: establish the external price fact, update the price policy and freeze a new epoch. Count/revision API conformance is unverified without a provider run.
- Preserve monetary storage even in ordinary AI builds with assist disabled; only the new API is feature-gated. Rejected: allowing another build to discard reservations when rewriting its existing ledger. Reversal cost: retain/read the additive storage namespace until explicit reconciliation; removing it would invalidate spend continuity.
- Forward the trusted parent CLI/MCP user-policy file separately from fixed credential lookup. Tool arguments cannot change that policy or gain startup authority. Rejected: silently falling back to the default policy when a human selected another deny policy. Reversal cost: no intended reversal; this preserves the existing authority boundary.

Rejected: qualifying from model agreement, zero-cost defaults or a diagnostic oracle-text ceiling. Reversal cost: a newly preregistered scoring policy and epoch.
