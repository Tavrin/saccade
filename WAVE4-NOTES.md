Scope: Shared rules and Part A only. Worktree `wave4`, branch `feat/wave4`, starting at `cccd6e35d52f1472d7b51297cd20d75ea8127fe6` (Wave 3 source contract present). No web reads, provider calls, model downloads, browser runs or heavy gates during development.

- Use a separate feature-gated assist module and immutable sidecars. Reject authority-bearing response fields through closed schemas. Rejected: changing grounded explanation or deterministic verdict contracts. Reversal cost: remove assist registrations and feature; existing reports remain readable.
- Reuse canonical digests, root policy, provider HTTP authorization and the existing locked ledger. Monetary accounting extends that ledger in an isolated additive namespace. Rejected: another independently trusted HTTP client or ambient credential lookup. Reversal cost: remove assist extension; persisted reservations remain conservative audit receipts.
- Require requested pinned models plus returned revisions; no fallback aliases. Unknown usage retains the full reservation and produces unknown cost. Rejected: guessing zero cost or silently substituting models. Reversal cost: explicit policy version change and a new qualification epoch.

Lane 2 decisions:

- Historical reports contain only aggregate masks. Require a report-hash-bound individual-membership manifest and verify its union; absent provenance is unavailable. Rejected: inventing component attribution from a union or recovering pre-masked pixels. Reversal cost: extend future capture producers to emit this manifest directly; historical missingness remains.
- Reconciliation requires exact canonical per-image statements/geometry/citations after blind remapping. Rejected: model-generated paraphrase agreement as independent truth. Reversal cost: preregister and qualify an additional reconciliation policy; current conservative policy can reduce coverage.
- Jev evidence-need routing is deferred until its incremental value is demonstrated. Deterministic rules, vision and dependent support are candidate experimental components, not retained qualified components. Reversal cost: enable a separately measured routing adapter and new policy epoch.
- Batch durable core operations exist, but a public CLI/MCP Batch network surface is deferred: it needs a frozen plan carrying verifiable transitive source references, not just embedded provider payloads. Interactive commands never wait on Batch. Reversal cost: add that plan contract and registrations; the existing lifecycle and request-hash adapter can be reused.
